# WP6 / WP6-A — Incipit-Index Morphology Test (L5-M1 round)

*Builder round 2026-09-25 (design frozen 11:55 PDT, pre-registered before any statistic
ran); adversary round (Smaug) same afternoon. Inputs inherited frozen from WP2 (38,440 ZL
tokens); nperm=10,000 (adversary 20,000 on headline cells), seeds 555001/555002 (adversary
777601/777602), folio-cluster bootstrap B=5,000 on every headline statistic, checkpointed
crash-resume verified bit-identical.*

## Design intent

WP5 certified a page-level, both-face, section-modulated or- enrichment in the opening
line(s) of pages (see CONSTRAINTS.md A7). The L5 generation round asked Lucen for candidate
mechanisms; her top-ranked candidate (**M1, "incipit-index stamp"**) holds that the
page-initial or- tokens are a *formula* — a folio label, incipit convention, or filing
stamp written into the first line. Sharpest prereg prediction: page-initial or- tokens
should draw from a **narrower shape repertoire** than or- tokens in body lines.

Tests: T6a (shape entropy dH and type count, page-initial vs body, paired within-page
permutation stratified by section×arm), T6b (top-shape share dS), T6c (entropy decay by
line rank 1–4, characterization), T6d (falsification control — same statistics for the
qok/ok/qo/ol classes; if they narrow too, the effect is generic layout bias). Kill rule
fixed in advance: bootstrap CI ∋ 0 on both dH and dS → M1 gets no support.

## Master verdict

**KILLED — M1 gets no support from this corpus.** The prereg kill rule fired exactly as
written:

- **T6a (dH):** obs −0.3697 (page-initial *more* entropic than body), perm p_ge = .857,
  boot CI95 [−1.000, +0.656] ∋ 0.
- **T6b (dS):** obs −0.1140 (top shape, bare `or`, carries *less* of the page-initial
  cell: .607 vs .721 body), perm p_ge = .862, boot CI95 [−0.334, +0.074] ∋ 0.
- **Direction is opposite to the hypothesis** — and T6c shows entropy *declining* down
  the page (H by line rank: 2.326 / 1.785 / 1.748 / 1.482 bits). Line 1 is the most
  lexically diverse line, the reverse of "line 1 is formulaic".
- **T6d:** 0/4 control classes narrow → artifact branch correctly not taken.
- Currier B (the only powered arm) shows the same picture; Currier A is below the prereg
  power floor (11 page-initial tokens) and is descriptive only. IT replication was gated
  on a ZL pass and correctly skipped.

Whatever the certified page-opening or- concentration is, it is **not a restricted,
repeated formula**.

Independent rebuild from the frozen WP2 token table (not builder dumps), own code, own
seeds, 2× draws on headline cells. **KILLED CONFIRMED**: obs dH −0.369723 and dS −0.114011
reproduced exactly end-to-end; adversary p_ge .856/.860, boot CIs [−1.009, 0.638] /
[−0.325, 0.072], both ∋ 0. Derived token table multiset-equal on rebuild; or- class flag
0 mismatches over all 38,440 ZL rows (WP5 rule reused, not redefined); builder checkpoint
tail counts and the 17-exact-ties disclosure reproduce at full precision. Fabrication
screen **clean**. One doc-only defect (a row-count typo: 2,142, not 2,040); zero
substantive defects.

**NOT_PREREG lead filed by the adversary** (descriptive only): for high-frequency classes
qo/ol, first lines are significantly MORE lexically diverse than the within-page null
(qo dH p_le = .0001; ol dS boot CI [−0.256, −0.008] excludes 0 opposite-direction).
"First lines favor lexical variety" is a candidate mechanism for a future prereg round.
